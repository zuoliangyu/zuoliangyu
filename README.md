## 关于我

四川师范大学电子信息工程专业毕业。最初从 STM32、FPGA 和电子竞赛进入工程世界，现在主要在 **嵌入式系统、Rust / Tauri 与 AI 工具链** 的交叉处做开源项目。

我关注的不是“再做一个 Demo”，而是让工具真正进入日常工作流：能在本地运行、兼顾多个平台、处理真实数据，也能在出问题时给出明确反馈。从芯片调试、工程迁移，到 AI CLI 会话管理、文献获取和论文写作，我会尽量把重复劳动变成可复用的软件。

## 代表项目

### AI 开发者工具

- [AI Session Viewer](https://github.com/zuoliangyu/AI-Session-Viewer) — 统一浏览、搜索、统计、导出和恢复 Claude Code、Codex CLI、Grok CLI 本地会话；同时提供跨平台桌面端与 Linux Web 服务。
- [AI CLI Installer](https://github.com/zuoliangyu/ai-cli-installer) — 为 Claude Code / Codex CLI 提供镜像加速、下载校验、故障切换与一键安装，桌面端和 Web 端共享 Rust 核心。
- [CC Switch Web](https://github.com/zuoliangyu/cc-switch-web) — 在浏览器中管理多种 AI 编码工具的供应商、配置、订阅和本地会话。

### 嵌入式与电子工程

- [EK-OmniProbe](https://github.com/EmbeddedKitOrg/EK-OmniProbe) — 在 EmbeddedKitOrg 参与维护的跨平台嵌入式工具，整合固件烧录、源码级调试、RTT、串口终端与 BLE。
- [TI Toolbox](https://github.com/zuoliangyu/ti-toolbox) — 面向 TI MSPM0 的桌面工具，处理 Keil 环境配置、CCS / Keil 工程互转和严格构建验证。
- [STM32 Debug Configurator](https://github.com/zuoliangyu/STM32-Debug-Configurator) — 用图形界面生成和管理 VS Code Cortex-Debug 配置。
- [zuolan_signal](https://github.com/zuoliangyu/zuolan_signal) — 管理 STM32H7、STM32F4 + FPGA 等多种信号处理硬件方案的总控仓库。

### 学术与知识工作流

- [LaTeX Thesis Writing](https://github.com/zuoliangyu/LaTeX-Thesis-Writing) — 中文学位论文 LaTeX 模板、自动检查脚本与 AI 写作辅助技能。
- [wos-fetch](https://github.com/zuoliangyu/wos-fetch) — 本地连接已登录浏览器完成 Web of Science 检索、相关性筛选、全文获取和结构化导出。
- [NUEDC TOPIC](https://github.com/zuoliangyu/NUEDC_TOPIC) — 持续整理 1994—2025 年全国大学生电子设计竞赛赛题，并提供在线检索。
- [LQB TOPIC](https://github.com/zuoliangyu/LQB_TOPIC) — 蓝桥杯电子类历年真题整理。

### AI × 工程实践

- [multisim-spice](https://github.com/zuoliangyu/multisim-spice) — 让 AI 生成的 SPICE 网表先通过 ngspice 自检，再交付给 Multisim 仿真。
- [Taffy Studio](https://github.com/zuoliangyu/Taffy-Studio) — 探索共享 Rust 核心的多端大模型聚合应用。
- [micu-ai-lib](https://github.com/zuoliangyu/micu-ai-lib) — MICU AI 开放社区项目导览与聚合站。
